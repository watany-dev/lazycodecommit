# ADR 0008: 設定の pr.mergeOption をマージ方式の既定値にする

## Status

Accepted.

## Context

仕様の初版は `lazycc pr merge` で `--ff`、`--squash`、`--three-way` のどれか1つを
必ず指定させていた。一方で設定ファイルには `pr.mergeOption` があり、検証される
だけでどこからも読まれていなかった。リポジトリごとにマージ方式が決まっている
チームでは、毎回フラグを打つ手間がある。

## Decision

- `pr merge` でフラグがなければ `pr.mergeOption` を使う。フラグがあればフラグを
  優先する。どちらもなければ、これまでどおり終了コード 2 で方式の指定を求める。
- フラグを2つ以上渡したときは、設定があっても終了コード 2 にする。
- レビュー画面のマージ方式の選択は、`pr.mergeOption` の方式にカーソルを置いて
  開く。確認の手順は変えない。

## Consequences

- 設定を置かない人の振る舞いは変わらない。方式を選ばずにマージされることはない。
- 設定を置いた人は、フラグなしの `pr merge` がその方式でマージする。
