# ADR 0007: CI 結果の表示とコメントの下書き一括投稿

## Status

Proposed（watany の判断待ち）。

## Context

仕様書は次の 2 つを、後続フェーズに入れるか未決にしていた。

- CodeBuild と CodePipeline の結果を PR に表示する。
- レビュー画面でコメントを溜めて、まとめて投稿する。

どちらも仕様書のスコープ（PR 作成、ブランチ確認、コード閲覧、横断の受信箱、
レビュー）の外にある。CI 結果の表示は CodeBuild や CodePipeline の API と IAM
権限を新たに要する。CodeCommit にはレビューをまとめて投稿する API がないため、
一括投稿はクライアント側で下書きを保持し、1 件ずつ投稿することになる。

## Decision（推奨案）

どちらもフェーズ1〜4に入れない。フェーズ4の完了後に、使ってみて必要なら改めて決める。

## Consequences

- フェーズ1〜4の範囲と IAM 権限の表は仕様書のまま変わらない。
